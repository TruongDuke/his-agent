# Ảnh cho thesis

Bỏ tất cả ảnh chụp màn hình vào thư mục NÀY (thesis/images/).
LaTeX đã cấu hình \graphicspath{{images/}} nên chỉ cần đặt đúng tên file.

Tên file cần có (xem danh sách trong chat):
- hust.jpg            (logo bìa)
- ui-patient.png      (giao diện chat bệnh nhân)
- ui-doctor.png       (giao diện bác sĩ)
- ... (các ảnh tính năng khác)
